# Crowdpromotion

Idle venues + local organisers = activities that fund social projects. Madrid · 中文 / English / Español.

**Open `index.html`** — double-click works, no server or install needed.

- **Public site**: activities with photos, a live map of venues and the projects they fund, an animated money-flow calculator, the network of networks, project progress, and the path from attendee to organiser.
- **Booking**: transparent ticket breakdown before paying, QR ticket after.
- **Studio** (back office for venues and organisers): earnings charts, revenue vs profit, payouts, referral income, QR check-in and settlement, venue listing, and a 5-step activity wizard.

Every ticket is split: venue 70% · organiser 15% · social project 8% · referral fund 3% · platform 4%. Money is shown as *Expected* (bookings) or *Transferred* (after a completed, verified activity).

## Develop
Edit files in `_build/`, then:
```bash
python3 _build/build.py
```
Tests: open `_build/tests.html`. Details for contributors in [AGENTS.md](AGENTS.md).
